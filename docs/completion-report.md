Теоретические темы и внешний процесс fork/PR/review не объявляются освоенными/пройденными автоматически.

## Что удалено

- TeamService, AuthData/AuthResponse/Team/TeamResponse, DI-регистрация и 5 сценариев исключительно DEX. На стр. 126–130 это пример автора; практика стр. 131 требует CurrencyService.
- MemoryWorker с вложенным SafeHandle и 2 его теста. Практика IDisposable прямо совмещена с Stream: using в файловом экспорте сохранён.
- WordCount, PrintObjectProperties, неиспользуемый UpdateCurrency(ref Currency).
- Самодельные ManualClock/ManualTimer/NotifyingStorage. Теперь месячный сервис использует обычный Task.Delay; расчёт календаря и отмена тестируются отдельно.
- Самописный ограниченный Postman runtime, браузерный Playwright script/dependency и один дублирующий тест параллельного пополнения.
- Лишний DTO CurrencyConversion и неиспользуемый EmployeeService.SearchAsync. Конвертация возвращает decimal, поиск сотрудников через API и фильтры storage сохранены.
- Старый dex-api-notes.md с описанием необязательной внешней интеграции. Вывод о требованиях перенесён в карту первоисточника.

Из исходных 67 сценариев удалены 7 проверок удалённых авторских примеров, объединён 1 дубликат; 1 сложный календарный сценарий заменён 4 простыми. Получается 62 сценария. Ни один тест не отключён ради успешного результата; два validation tests из удалённого DEX-файла перенесены в BoundaryTests.

## Что сохранено и почему

Domain/App/Data и IStorage<T>/IClientStorage прямо требуются на стр. 58; API/DTO/DI/валидация — на стр. 123; Bogus — на стр. 33; FluentValidation — на стр. 123; CsvHelper — технология файлового раздела. EF Core/Npgsql нужны для PostgreSQL. SQLite служит только безопасным тестовым хранилищем.

Сохранены все обязательные банковские операции, LINQ, async/await, отмена, потоковая обработка, события, Equals/GetHashCode, reflection, обобщённый JSON и SQL. Lock, semaphore и concurrency token обеспечивают корректность уже заданной многопоточной работы; дополнительная банковская функциональность не добавлялась.

Задания Bonus/blacklist и Currency entity сохранены как прямо указанные дополнительные упражнения. Изучение AutoMapper/Newtonsoft не подменяется заявлением о владении библиотеками; явный mapping и System.Text.Json выполняют практические требования.

## Что стало проще

Контроллеры поиска используют явные переменные; правила Bogus записаны отдельными шагами; генерация словаря и сотрудников — обычными циклами. EF Get/GetAsync развёрнуты до формирования query и вызова ToList. Дублирующая валидация DataAnnotations удалена, FluentValidation остался. Regex.IsMatch заменил GeneratedRegex. Из reflection удалён лишний overload Create(Type), делегат InvokeThenRemove больше не возвращает фиктивную константу.

ConsoleApp4 теперь является отдельным калькулятором из стр. 142, а не Hello World. BankSystem.Data.Tests добавлен по прямому указанию стр. 113; туда перенесены EF-проверки. **Всего 9 проектов**, включая 2 тестовых и 2 консольных, без новых продуктовых слоёв.
